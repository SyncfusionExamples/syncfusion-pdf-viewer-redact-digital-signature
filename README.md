# Syncfusion ASP.NET Core PDF Viewer with Digital Signature and Redaction

## Overview

This sample demonstrates how easily **digital signature** and **redaction** support can be integrated into the **Syncfusion ASP.NET Core PDF Viewer**.

The solution uses:

- Built-in **redaction tools** available in the Syncfusion PDF Viewer.
- **Syncfusion PDF Library (EJ2 PDF Library)** for digital signature creation, validation, and management.
- ASP.NET Core **Partial Views** for seamless integration into existing applications.

## Features

### Redaction Support
- Built-in redaction tools within the Syncfusion ASP.NET Core PDF Viewer.
- Permanently remove sensitive information from PDF documents.
- User-friendly redaction workflow integrated into the viewer toolbar.

### Digital Signature Support
- Create digital signatures for PDF documents.
- Validate existing digital signatures.
- Manage signature information using the Syncfusion PDF Library.
- Demonstrates server-side processing of PDF signatures.

### ASP.NET Core Integration
- Easy integration into ASP.NET Core applications.
- Uses Partial Views for embedding the PDF Viewer solution.
- Provides a simple reference implementation for enterprise applications.

## Prerequisites

Before running the sample, ensure you have:

1. Clone the repository.
